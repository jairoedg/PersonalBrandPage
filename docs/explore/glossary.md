# Glossary — Personal Brand Website Explore

**Status**: Approved terminology index derived from canonical A3/domain vocabulary
**Authority**: `explore/explore-personal-brand-website/domain-analysis.md` (A3)

| Term | Meaning / usage |
|---|---|
| Project | Canonical professional delivery/work record validated through the A3 lifecycle. |
| Project Story | Curated public narrative derived from a validated Project; it is not the same object as a Project. |
| Evidence | Supporting factual material governed for adequacy, attribution, sensitivity, and publication use. |
| Content Owner | Product Owner authority for semantic content judgment and final public-content approval. |
| Project Story Curation / Publication Governance | Logical responsibility for transforming validated Projects into approved public narratives and governing eligibility. |
| Context Warehouse / Professional Knowledge | Logical responsibility for governed professional facts, validated Projects, Evidence, references, and sensitivity metadata; not the public runtime source. |
| Public Website Experience | Logical responsibility for visitor-facing presentation, navigation, progressive disclosure, and approved Contact paths. |
| Publication eligibility | Deterministic structural conditions that must pass before public generation; not proof of semantic truthfulness. |
| Human semantic governance | Human judgment for Evidence adequacy, attribution, truthful wording, narrative qualification, disclosure, semantic publication suitability, and Content Owner approval. |
| Combined delivery responsibility | DEC-004 logical responsibility for approved-content preparation and public generation; does not imply a repository, service, process, deployment unit, or runtime topology. |
| External Destinations | Approved outbound links/downloads such as LinkedIn, email, phone, and CV actions. |
| Measurement | Conditional future concern under DEC-007; not an automatically selected analytics architecture. |
| Leadership Principle | Canonical A3 professional concept used by approved supporting experience/content. |
| Career Experience | Canonical professional-history concept used by the approved domain and experience model. |

This glossary does not select implementation technology, file format, schema, tooling, hosting, breakpoints, accessibility conformance, analytics, or physical topology.
