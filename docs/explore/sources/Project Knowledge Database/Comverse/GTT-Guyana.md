# GT&T Guyana – VAS Platform Implementation

**Company:** Comverse (later Mavenir)  
**Client:** GT&T Guyana  
**Period:** March 2012 – November 2012
**Role:** Senior Project Lead — On-site Implementation Lead  
**Industry:** Telecommunications  
**Country:** Guyana  
**Delivery Model:** Waterfall  
**Status:** Production Go-Live Completed

---

## Leadership Theme

Learning Delivery Discipline

---

## Business Context

Greenfield implementation of a new Value Added Services (VAS) platform for the Guyanese telecommunications operator.

The implementation required integration with multiple existing telecommunications platforms, including prepaid charging systems.

---

## My Mission

Lead on-site implementation activities while coordinating multiple technical workstreams and maintaining continuous communication with customer stakeholders.

---

## Leadership Focus

- Coordinated implementation teams.
- Managed technical dependencies.
- Produced weekly status reports.
- Managed risks and blockers.
- Maintained customer communication throughout the project.

---

## Results

Successful implementation and production deployment.

Although the project experienced a moderate schedule extension, implementation quality remained stable and customer communication remained transparent throughout execution.

---

## Leadership Reflection

This project reinforced that disciplined execution, consistent communication, and proactive dependency management are often enough to deliver successful outcomes when the project environment is stable.

---

## Leadership Principles

- Predictable delivery comes from disciplined communication.
- Consistency builds customer confidence.
- Good planning reduces implementation uncertainty.
